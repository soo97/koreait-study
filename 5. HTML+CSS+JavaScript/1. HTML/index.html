설명 : 제목을 나타내는 태그이며 숫자가 커질수록 중요도 낮음



<strong> <b> 문자 강조

b 설명 : 중요하거나 강조되어야 하는 내용을 시각적으로만 나타냄

차이점 : strong은 스크린 리더 등의 사용자에게 중요한 내용임을 알려줌

strong입니다. b 입니다.

설명 : 기본 문자보다 작게 표시하는 태그

small입니다.

< u> <s> 밑줄과 취소선

u설명 : 글자에 밑줄을 표시하는 태그

s설명 : 글자에 취소선을 표시하는 태그

u 태그 입니다. s 태그 입니다.

<sup> <sub> 첨자

sup설명 : 위 첨자로 나타내는 태그
